Your agent, unleashed.
Your Mac, untouched.

Corral is a sandbox for AI coding agents. Every project gets its own small Linux machine. Your agent works there at full speed with no permission prompts, while your SSH keys, Keychain and other projects stay out of reach.

$ brew install corral-sh/tap/corral

macOS 13.5+ · Apple Silicon and Intel · Apache-2.0

Inside the corral

the agent's world

A Linux VM just for this project. The agent can install, build, run and break things freely.

  • your project folder
  • the agent, with sudo
  • node · go · python · docker
  • the hosts you allow

Outside the fence

your Mac

Everything else on your Mac. Not hidden, not filtered: simply not there for the agent to find.

  • ~/.ssh keys
  • Keychain
  • other repositories
  • the rest of your home folder
Get started

Three commands. That's the whole workflow.

  1. 1

    Install

    brew install corral-sh/tap/corral

    Homebrew builds it from source and brings Lima, the VM engine.

  2. 2

    Open a project

    cd ~/Code/my-app

    Any folder works. Each project gets its own box.

  3. 3

    Start your agent

    corral claude

    The first box takes a few minutes, once. After that a new project is ready in about 15 seconds.

Freedom for the agent. Peace of mind for you.

A real boundary

One virtual machine per project. If something goes wrong, it happens in an empty Linux box, not in your home folder.

Full speed

No permission prompts to click through. Your project appears at its real path, and each run adds about a second.

You choose what it can reach

Optionally limit the internet to the sites you list. Your Mac enforces it, and blocked attempts are logged.

Undo, built in

A snapshot is taken every time a session starts. One command rolls the box back.

Questions

What does Corral do?

It creates a small Linux virtual machine for each project on your Mac, using Apple's built-in virtualization through Lima. Your AI coding agent runs inside it with full permissions, but it can only see that project, not the rest of your Mac.

Is it free?

Yes. Corral is open source under the Apache-2.0 licence. You only need an account with the AI agent you use.

How is it different from running the agent in Docker?

Docker on a Mac runs every container inside one shared VM that can see your /Users folder. Corral gives each project its own VM, so a mistake or a malicious package in one project can't reach your home folder or your other projects.

What do I need?

A Mac with macOS 13.5 or newer (Apple Silicon or Intel) and Homebrew. Everything else is in the docs.
