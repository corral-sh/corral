# GitHub profile images

Rendered by `tools/brand/render.sh` from `tools/brand/card.html`. GitHub has no API
for either upload, so after re-rendering, upload them by hand:

| File | Where | Size |
|---|---|---|
| `avatar.png` | github.com/organizations/corral-sh/settings/profile → Profile picture | 1024×1024 |
| `social-preview.png` | github.com/corral-sh/corral/settings → General → Social preview | 1280×640 (GitHub's recommended 2:1) |

The social preview is the card shown when the repository link is shared (Slack, X,
LinkedIn…); the website's own card is `site/assets/og.png`.
